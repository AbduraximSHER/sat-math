# SAT Math — o'qituvchi qo'llanmasi

Bilingual (EN/UZ) Digital SAT Math teacher guide and classroom site.

- 44 lessons with deepened explanations
- 100 checked practice items per lesson
- Answer keys load only when the teacher opens the key

## Site

```bash
cd site
npm install
npm run dev
```

## Rebuild content

```bash
python3 -m pip install -r requirements.txt
python3 -m guide.build_guide
```
